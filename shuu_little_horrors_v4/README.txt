LITTLE HORRORS — SHUU REIMAGINED (v5)

Open index.html in a modern browser.

Controls:
  WASD / Arrow keys  Move / select choices
  Z / Enter / Space  Interact / confirm / advance dialogue

This version keeps the sprite-based look of the original demo but adds:
  - a cleaner, more readable objective system
  - stronger room-to-room flow and atmosphere
  - better pacing on the medicine quest
  - clearer final loop and end-state presentation
  - richer UI treatment with sharper message panels and foggy, unsettling effects

This build uses the supplied Shuu and Madoka sprite sheets.
